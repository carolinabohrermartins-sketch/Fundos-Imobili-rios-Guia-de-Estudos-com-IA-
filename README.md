# Fundos-Imobili-rios-Guia-de-Estudos-com-IA-
Guia de estudos sobre Fundos Imobiliários (FIIs), desenvolvido com apoio do NotebookLM e da Inteligência Artificial. O projeto reúne fontes selecionadas, análises, prompts e aprendizados, com o objetivo de organizar conhecimentos sobre FIIs e desenvolver uma metodologia de estudo utilizando IA.
